## Використані команди
- `git init` — ініціалізація локального сховища.
- `git config` — конфігурація імені та пошти розробника.
- `git remote add` — підключення віддаленого репозиторію.
- `git add .` та `git commit` — фіксація змін.
- `git push` — завантаження коду на GitHub.
- `git checkout -b` — створення нової робочої гілки.
- `git merge` — інтеграція змін з іншої гілки в основну.
